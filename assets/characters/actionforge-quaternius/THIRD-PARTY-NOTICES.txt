Who made what in this repository, and under which terms. `LICENSE` has the
terms themselves; this file is the attribution record, and the build copies it
into the published `THIRD-PARTY-NOTICES.txt`.

  `assets/animation-library/animations/`) — created by
  [Quaternius](https://quaternius.com) and dedicated by him to the public domain

  and repackaged — and everything it adds on top is dedicated under the same
  terms. More of his work, and support for it:
  [quaternius.com](https://quaternius.com),
  [patreon.com/quaternius](https://www.patreon.com/quaternius).
- **Props** (`assets/animation-library/props/`) — CC0 1.0, as `LICENSE` says.
- **Mixamo reference skeleton** (`assets/animation-library/skeletons/`) — a
  third-party file from Adobe, used as a retargeting reference. Not covered by
  CC0; subject to Adobe's own terms.

## Bundled code

npm packages bundled into the published build are listed, with their licence
texts, in `THIRD-PARTY-NOTICES.txt`, which `scripts/build.mjs` generates from the
build's own metafile (three.js, MIT; @comfyorg/fbx-exporter-three, MIT).

## Ported source

Code copied or adapted from another project into `scripts/` counts as ours to
the bundler — it is minified and obfuscated with everything else, and appears in
no package list — so its notice has to be kept here, by hand.

- **None at present.** A preview recorder ported from
  [Mesh2Motion](https://github.com/Mesh2Motion/mesh2motion-app) (MIT,
  "Copyright (c) 2025 Scott Petrovic") shipped earlier and has since been
  removed. `zip-store.js` replaces the JSZip that Mesh2Motion's generator used;
  it is our own code.

When ported code lands, add an entry here: the file, the project, the licence
and its copyright line verbatim — and, for MIT, keep the full notice in the
file's header as a `/*! … */` comment, which the build preserves.
