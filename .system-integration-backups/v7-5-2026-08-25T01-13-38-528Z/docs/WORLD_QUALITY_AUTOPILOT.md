# WORLD QUALITY AUTOPILOT V6

Technology-aware, CPU-first, non-destructive closed-loop quality layer for World_server.

`Scout technologies → Route detail → Route optimization → Analyze → Budget → Improve → Optimize → Replay → Compare → SLO → Tournament → Canary → Accept/Rollback`

V6 guarantees:

- graphics technology scout runs before every world-quality cycle;
- each runtime-detected graphics technology requires both a detail adapter and an optimization adapter;
- declared-only/runtime-unverified technology is never silently counted as active;
- unknown graphics packages require explicit adapter review;
- CPU-first/free-local route is preferred and paid GPU is never a required dependency;
- exact front-projection preservation for reference-derived voxel worlds;
- deterministic semantic detail with importance/hero budgets;
- material/PBR metadata plus non-destructive texture-bake recipes;
- adaptive runtime quality using FPS/P95/GPU/long-task/memory/device pressure;
- conservative visibility, streaming topology and neighbor prefetch;
- animation semantic validation, retarget contract and distance LOD;
- deterministic controls/physics replay contracts;
- multi-view visual gate that counts only explicit human/user-approved non-synthetic aesthetic baselines;
- synthetic/emulated evidence validates contracts but cannot unlock production 100%;
- shader-cost auditing, quality SLO/error budgets, causality guard, winner-only policy and rollback;
- technology drift lock so a newly appeared runtime technology is visible until integration is reviewed;
- tamper-evident provenance-aware evidence ledger.

Structural target: **99%**. Technology connectivity target: **100%** for runtime-detected supported technologies. Production-proof target: **100% only with explicit multiview visual approval, real rig playback, physical iOS/Android evidence and deployment canary evidence.**
