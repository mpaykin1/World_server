# V9 Error Immunity + Safe Propagation

Failure path: `production replay → global fingerprint → quarantine/BLOCK → root cause → shared-core fix → prevention rule → mandatory regression → Protection Pack → Ratchet → representative canary → compatible consumers → drift audit → rollback on regression`.

Success path: `measured improvement → source/near fidelity 100% → p99/hitch PASS → applicability proof → repeated evidence → Quality Genome → canary → compatible consumers → drift verification`.

V9 additionally protects CPU-only operation: paid/discrete server GPU dependencies, full-world rebuilds after local changes, lossy autotuning, near-field PVS/occlusion mistakes, wrong-source nav/collision caches and background CPU bake starvation are permanent protected failure classes.

## V10 усиление

V10 добавляет permanent protection для bounded-memory parsing, threaded importer parity, semantic PVS, incremental GI reuse, content-defined chunks, offline/shared cache SHA isolation, lossless cache codec, exact binary delta, CPU flamegraph evidence, deterministic network/physics replay farm и dependency impact graph. Protection Pack теперь покрывает 55 известных recurring fingerprints; неизвестная ошибка остаётся release-blocking quarantine до root cause + rule + test + shared fix.
