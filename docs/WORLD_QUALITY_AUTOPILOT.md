# World Quality Autopilot V4

V4 is a non-destructive closed-loop quality layer for `World_server`.

Pipeline:

`Analyze → Semantic Detail → Material/PBR Synthesis → Visibility/Texture Budget → Animation Contract → Runtime Pressure → Candidate Lab → Cost/Quality Schedule → Regression Gates → Evidence Ledger → Accept/Reject`.

Hard invariants:
- Never mutate the reference-facing voxel projection.
- Never replace approved Golden graphics with lower-quality output.
- Never bypass controls, collisions, mobile or performance gates.
- Never self-approve aesthetic baselines.
- Never mutate `master`/`main` or auto-merge.
- Telemetry/learning may recommend changes but cannot apply them without candidate + regression gates.

V4 adds deterministic procedural PBR profiles, texture/virtual-atlas budgets, conservative sector visibility, sustained-pressure/thermal proxy detection, universal retarget contract, production feedback learner, candidate lab and cost-quality scheduler.
