# ЭТАЛОННЫЙ сценарий автодемонстрации World_server

**Статус: CANONICAL / ЭТАЛОН.**

Этот документ — источник истины для реализации автодемонстрации возможностей стэка. Реализация, QA и будущие изменения сценария должны сверяться с ним. Менять смысл сценария без явного нового решения владельца проекта нельзя.

## Правила демонстрации

- Демонстрация запускается автоматически, когда пользователь входит в мир.
- Демонстрация — не кино, а игра с выбором: каждый этап показывает возможность стэка, затем спрашивает игрока, что должно случиться дальше.
- Игрок всё время может ходить, прыгать, смотреть по сторонам и взаимодействовать с миром.
- После крупных изменений игрок получает примерно 1 минуту на свободное исследование происходящего.
- Титры должны быть простыми и понятными ребёнку примерно 5 лет.
- На экране одновременно показывается только один язык.
- Сверху есть одна маленькая кнопка `RU`; после нажатия она становится `EN`, и все титры, варианты выбора, канон и подсказки переключаются без перезапуска мира и демонстрации.
- Все другие игроки на текущем этапе — ИИ-персонажи.
- В демонстрации должны появляться и трансформироваться существа из установленного редактора существ.
- Ни один выбор не должен заканчиваться только текстом: выбор игрока должен приводить к реально видимому изменению мира, существа, ИИ, предмета, погоды, боя или другого мира.

## Эталонная последовательность титров

1. **«Добро пожаловать! Этот мир живой.»**  
   Игрок получает минуту, чтобы свободно походить и всё рассмотреть.

2. **«Куда пойдём?»**  
   Выбор: **Лес / Горы / Берег / Пустыня**  
   Мир начинает достраиваться в выбранном направлении.

3. **«Смотри! Мир растёт вокруг тебя.»**  
   Перед игроком появляются новые участки земли, растения, скалы, вода, деревья и дальние объекты.

4. **«Что изменить в мире?»**  
   Выбор:
   - **🌅 Сделать закат** — небо становится золотым, оранжевым и красным. Над горизонтом появляется огромное солнце. Сквозь объёмные облака проходят яркие лучи света — god rays.
   - **☄️ Сделать ночь** — небо темнеет, появляются звёзды. Над миром пролетают большие яркие огненные кометы с длинными светящимися хвостами.
   - **⛈️ Начать грозу** — небо темнеет, сверкают молнии, гремит гром, начинается дождь, над землёй появляется туман.
   - **🍃 Усилить ветер** — деревья, кусты и трава раскачиваются. По воздуху летят листья и лепестки цветов. Всё выглядит кинематографично.

5. **«Мир услышал тебя.»**  
   Выбранный эффект разворачивается прямо вокруг игрока. Игрок получает время походить внутри изменившегося мира.

6. **«Кто здесь появится?»**  
   Выбор: **Маленькое существо / Большое существо / Летающее существо / Странное существо**

7. **«Смотри! Родилось новое существо.»**  
   Существо создаётся через редактор существ прямо на глазах игрока и начинает двигаться.

8. **«Как его изменить?»**  
   Выбор: **Сделать больше / Добавить крылья / Добавить рога / Изменить тело**

9. **«Существо меняется!»**  
   Игрок видит сам процесс трансформации: тело растёт, появляются новые части, меняются пропорции и движение.

10. **«Как оно будет себя вести?»**  
    Выбор: **Следовать за мной / Исследовать мир / Искать других существ / Атаковать врагов**

11. **«Кто будет врагом?»**  
    Выбор: **Дикие чудовища / Каменные монстры / Вражеские существа / Разбойники**

12. **«Как наше существо будет сражаться?»**  
    Выбор: **Атаковать вблизи / Стрелять издалека / Защищать хозяина / Нападать группой**

13. **«Смотри! Начался бой.»**  
    На экране видно полоски здоровья, удары и попадания, отбрасывание, вспышки и частицы, поведение ИИ и победу одного из участников.

14. **«Что взять после победы?»**  
    Выбор: **Золото / Редкий предмет / Кристалл / Еду**

15. **«Существо научилось новому.»**  
    Оно запоминает выбранное поведение и продолжает использовать его в мире.

16. **«Ты можешь менять этот мир.»**  
    Выбор, что создать: **Дом / Мост / Башню / Озеро / Сад / Пещеру / Маленькую крепость**

17. **«Что построим?»**  
    Игрок выбирает объект. Мир начинает физически меняться прямо перед ним.

18. **«Мир запомнил твоё действие.»**  
    Короткий титр: **«Сохранено.»**

19. **«К нам пришёл другой игрок.»**  
    В мире появляется ИИ-игрок.

20. **«Что попросить его сделать?»**  
    Выбор: **Построить башню / Выкопать шахту / Построить мост / Найти пещеру**

21. **«ИИ начал действовать.»**  
    Игрок может ходить рядом и наблюдать за его работой.

22. **«Что будем искать?»**  
    Если построена башня: **Сундук с золотом / Старинное оружие / Тайную комнату / Магический предмет**  
    Если выкопана шахта: **Золото / Алмазы / Кристаллы / Древний артефакт**

23. **«Сокровище где-то рядом.»**  
    Игрок получает направление, но должен сам пройти внутрь башни, шахты или пещеры и найти предмет.

24. **«Нашёл!»**  
    Сундук открывается, предмет физически появляется и попадает игроку.

25. **«Пришли ещё жители.»**  
    Появляются несколько ИИ-персонажей.

26. **«Что они должны делать вместе?»**  
    Выбор: **Построить поселение / Исследовать мир / Создать дорогу / Исследовать шахту / Построить крепость**

27. **«Они начали работать вместе.»**  
    ИИ-персонажи расходятся по задачам, но результат появляется в одном общем мире.

28. **«У этого мира есть история.»**

29. **«Что найдём?»**  
    Выбор: **Древнюю постройку / Таинственный предмет / Следы огромного существа / Загадочное место**

30. **«Что произошло здесь раньше?»**  
    Выбор и реакция мира:
    - **Здесь жили великаны** → появляются огромные следы ног, гигантские двери, разрушенные дома и кости огромных существ.
    - **Здесь открыли портал** → появляется древняя площадка, начинает светиться портал, вокруг возникают странные частицы и предметы из другого мира.
    - **Здесь пропало поселение** → появляются пустые дома, брошенные вещи, погасшие костры и следы жителей, ведущие в неизвестное место.
    - **Здесь появилось неизвестное существо** → появляются следы, сломанные деревья, звуки издалека, затем игрок впервые видит само существо.

31. **«Теперь это часть истории мира.»**  
    Появляется маленькая кнопка: **«Смотреть канон»**

32. **«Смотреть канон»**  
    При нажатии открывается простая история выбранного события. Там же показываются новые события игроков и ИИ.

33. **«Что должно случиться дальше?»**  
    Выбор: **Открыть портал / Разбудить существо / Построить крепость / Начать экспедицию**

34. **«История меняет сам мир.»**  
    Портал действительно открывается, существо просыпается, крепость физически строится, экспедиция из ИИ-персонажей реально отправляется в путь — согласно выбору игрока.

35. **«Твои поступки тоже становятся историей.»**

36. **«Что ты сделаешь?»**  
    Выбор: **Освободить пленника / Победить вожака врагов / Открыть древний сундук / Закрыть портал / Приручить редкое существо**

37. **«Твой поступок стал частью канона.»**  
    Кнопка **«Смотреть канон»** сразу показывает новую запись.

38. **«Твой поступок изменил будущее.»**  
    Последствия:
    - **Освободил пленника** → он приводит новых жителей и появляется маленькое поселение.
    - **Победил вожака врагов** → вражеский лагерь исчезает, территория становится безопасной.
    - **Открыл древний сундук** → найденный предмет активирует древнее сооружение.
    - **Закрыл портал** → существа перестают приходить, вокруг портала меняется территория.
    - **Приручил редкое существо** → оно начинает путешествовать рядом с игроком и появляется в истории мира.

39. **«Другой мир узнал о случившемся.»**  
    Игрок видит большой светящийся сигнал в небе. На экране появляется сообщение: **«Событие дошло до соседнего мира.»**

40. **«Что появится в соседнем мире?»**  
    Выбор: **Посланник / Новое существо / Руины / Следы события**

41. **«Проверим соседний мир?»**  
    Появляется кнопка: **«Проверить соседний мир»**

42. После нажатия игрок переносится через портал в соседний мир.

43. **«Смотри! Здесь уже есть последствия твоего выбора.»**  
    Если выбран:
    - **Посланник** → рядом стоит ИИ-персонаж и рассказывает о событии.
    - **Новое существо** → существо физически живёт в этом мире.
    - **Руины** → появляется разрушенная постройка, связанная с предыдущим событием.
    - **Следы события** → видны предметы, следы, растения, изменения земли и окружения.

44. **«Все миры связаны.»**  
    Игрок видит простую карту: **Мир 1 → твоё событие → Мир 2**. Нажатие на каждый мир открывает его.

45. **«Хочешь проверить связь ещё раз?»**  
    Кнопка: **«Вернуться в первый мир»**  
    Игрок возвращается и видит, что исходное событие никуда не исчезло.

46. **«Создадим новый мир?»**  
    Кнопка: **«Создать мир»**

47. **«Каким он будет?»**  
    Выбор: **Ледяной / Зелёный / Вулканический / Небесный**

48. **«Кто будет там жить?»**  
    Выбор: **Драконы / Великаны / Маленькие существа / Неизвестная цивилизация**

49. **«Создаём землю…»**  
    Земля появляется перед игроком.

50. **«Создаём воду, растения и небо…»**

51. **«Создаём существ…»**  
    Через редактор существ появляются новые обитатели.

52. **«Создаём историю…»**

53. **«Связываем новый мир с остальными…»**

54. **«Проверяем, красиво ли получилось…»**

55. **«Готово! Новый мир родился.»**

56. **«У тебя есть минута, чтобы его исследовать.»**  
    Игрок свободно гуляет без обязательных действий.

57. **«Что изменить в новом мире?»**  
    Выбор:
    - **Создать огромную гору** → гора растёт прямо перед игроком.
    - **Создать большое озеро** → земля опускается и заполняется водой.
    - **Посадить волшебный лес** → быстро появляются деревья, растения, цветы и существа.
    - **Построить древний город** → начинают появляться улицы, стены, дома и башни.

58. **«Что добавить в новый мир?»**  
    Выбор: **Новое существо / Вражеский лагерь / Сокровища / Портал в другой мир**

59. **«Что должно произойти здесь?»**  
    Выбор: **Начать праздник / Начать грозу / Начать нападение врагов / Найти древнюю тайну**

60. **«Мир продолжает меняться вместе с тобой.»**

61. **«Играй. Строй. Создавай существ. Сражайся. Находи сокровища. Меняй историю.»**

62. **«Теперь решаешь ты.»**

После финального титра демонстрация заканчивается, но ничего не перезапускается: пользователь остаётся именно в этом живом мире и продолжает играть.

## Поведение титров

- Крупный титр показывается примерно 5–7 секунд.
- Затем он уменьшается в компактную подпись, а игрок продолжает свободно исследовать происходящее.
- Следующий этап запускается после демонстрации эффекта и предусмотренного времени исследования.
- Игрок не теряет управление во время титров и визуальных эффектов.
- Любое действие, заявленное титром, должно быть подтверждено видимым игровым результатом.
