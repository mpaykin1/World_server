# Автодемонстрация возможностей World_server

## Правила демонстрации

- Демонстрация запускается автоматически, когда пользователь входит в мир.
- Игрок всё время может ходить, прыгать, смотреть по сторонам и взаимодействовать с миром.
- Каждый этап начинается с простого крупного титра.
- После титра игрок получает примерно 1 минуту на свободное исследование происходящего.
- Игра регулярно предлагает игроку выбор, что должно случиться дальше.
- Титры показываются на одном выбранном языке. В интерфейсе должна быть кнопка переключения RU / EN без перезапуска демонстрации.
- Все другие игроки на текущем этапе — ИИ-персонажи.
- В демонстрации должны появляться и трансформироваться существа из установленного редактора существ.
- Титры должны быть понятны ребёнку примерно 5 лет.

## Последовательность титров

1. **«Добро пожаловать! Этот мир живой.»**  
   Игрок получает минуту, чтобы свободно походить и всё рассмотреть.

2. **«Куда пойдём?»**  
   Выбор: **Лес / Горы / Берег / Пустыня**  
   Мир начинает достраиваться в выбранном направлении.

3. **«Смотри! Мир растёт вокруг тебя.»**  
   Появляются новые участки земли, растения, скалы и вода.

4. **«Что изменить в мире?»**  
   Выбор:
   - **Сделать закат** — небо становится золотым и красным, появляется огромное солнце, сквозь облака проходят яркие god rays.
   - **Сделать ночь** — темнеет небо, загораются звёзды, над миром пролетают большие яркие огненные кометы.
   - **Гроза** — небо темнеет, сверкают молнии, гремит гром, начинается сильный дождь и стелется туман.
   - **Усилить ветер** — деревья и трава раскачиваются, по воздуху летят листья и лепестки цветов, всё выглядит красиво и кинематографично.

5. **«Мир услышал тебя.»**  
   Выбранное изменение происходит прямо перед игроком.

6. **«Кто здесь появится?»**  
   Выбор: **Маленькое существо / Большое существо / Летающее существо / Странное существо**

7. **«Смотри! Родилось новое существо.»**  
   Существо создаётся системой редактора существ и начинает двигаться по миру.

8. **«Как его изменить?»**  
   Выбор: **Сделать больше / Добавить крылья / Добавить рога / Изменить тело**

9. **«Существо меняется!»**  
   Трансформация происходит прямо перед игроком.

10. **«Как оно будет себя вести?»**  
    Выбор: **Следовать за мной / Исследовать мир / Искать других существ / Строить себе дом**

11. **«Существо научилось новому.»**  
    Оно начинает выполнять выбранное действие.

12. **«Ты можешь менять этот мир.»**  
    Игроку предлагают сломать блок, поставить блок, построить простой объект.

13. **«Мир запомнил твоё действие.»**  
    Короткий титр: **«Сохранено.»**

14. **«К нам пришёл другой игрок.»**  
    В мире появляется ИИ-игрок.

15. **«Что попросить его сделать?»**  
    Выбор: **Построить башню / Посадить лес / Найти существо / Исследовать пещеру**

16. **«ИИ начал действовать.»**  
    Игрок может ходить рядом и наблюдать за его работой.

17. **«Пришли ещё жители.»**  
    Появляются несколько ИИ-персонажей.

18. **«Что они должны делать вместе?»**  
    Выбор: **Построить поселение / Исследовать мир / Создать дорогу / Защищать это место**

19. **«У этого мира есть история.»**  
    В мире появляется объект истории: древняя постройка, предмет, следы существа, необычное место.

20. **«Что произошло здесь раньше?»**  
    Выбор: **Здесь жили великаны / Здесь открыли портал / Здесь пропало поселение / Здесь появилось неизвестное существо**

21. **«Теперь это часть истории мира.»**  
    Выбранное событие становится каноном.

22. **«Что должно случиться дальше?»**  
    Выбор: **Открыть портал / Разбудить существо / Построить крепость / Начать экспедицию**

23. **«История меняет сам мир.»**  
    Карта физически изменяется согласно выбору игрока.

24. **«Твои поступки тоже становятся историей.»**  
    Игрок делает простое действие, которое записывается в канон.

25. **«Твой поступок изменил будущее.»**  
    Появляется заметное последствие.

26. **«Другой мир узнал о случившемся.»**  
    Возникает связь с другим миром.

27. **«Что появится в соседнем мире?»**  
    Выбор: **Посланник / Новое существо / Руины / Следы события**

28. **«Все миры связаны.»**  
    Игрок видит, как одно событие получает продолжение в другом мире.

29. **«Создадим новый мир?»**  
    Кнопка: **«Создать мир»**

30. **«Каким он будет?»**  
    Выбор: **Ледяной / Зелёный / Вулканический / Небесный**

31. **«Кто будет там жить?»**  
    Выбор: **Драконы / Великаны / Маленькие существа / Неизвестная цивилизация**

32. **«Создаём землю…»**

33. **«Создаём существ…»**

34. **«Создаём историю…»**

35. **«Связываем новый мир с остальными…»**

36. **«Готово! Новый мир родился.»**

37. **«У тебя есть минута, чтобы его исследовать.»**

38. **«Что изменить в новом мире?»**  
    Игрок снова получает несколько простых вариантов выбора.

39. **«Мир продолжает меняться вместе с тобой.»**

40. **«Играй. Строй. Создавай существ. Меняй историю.»**

41. **«Теперь решаешь ты.»**

## Поведение титров

- Крупный титр показывается примерно 5–7 секунд.
- Затем он уменьшается в компактную подпись, а игрок продолжает свободно исследовать происходящее.
- Следующий этап запускается примерно через минуту.
- Игрок не теряет управление во время титров и визуальных эффектов.
- Выбор игрока должен приводить к реально видимому изменению мира, а не только к текстовому сообщению.
