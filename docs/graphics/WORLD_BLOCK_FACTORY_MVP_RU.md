# World Block Factory — CPU-first MVP

Канонический контракт: `shared/graphics/world-block-factory.mjs`. Идентичная копия для статической cinematic: `scratch-chain-reaction/cinematic/world-block-factory.mjs` (проверять SHA256 при каждом обновлении).

## Проверенная инвентаризация

- `apps/voxel-world/client.js`: уже есть 16×16 чанки, Three.js, детерминированный seed, биомы и выбор видимых чанков; код не переписывался.
- `apps/ai3d-voxel-city/mesher-worker.js`: существующий greedy mesher скрытых граней — повторное использование предусмотрено для следующего 3D-этапа, в Canvas2D MVP не требуется.
- PR #336: 8 оригинальных GLB и CPU Blender-конвейер, но PR Draft. Эти ресурсы НЕ включены в этот выпуск и не считаются опубликованными.
- Cinematic: существующие `chain-engine.mjs`, `idea-parser.mjs` и локальное сохранение переиспользуются без замены рендерера.
## Реализованный контракт и браузерный MVP

13 декларативных типов, координаты и отрицательные чанки, seed, ID, biome/sockets, license и четыре quality-tier. Простая процедурная карта отрисовывается на Canvas2D; объекты сохраняют ID при переключении уровня графики. Браузерный маршрут новой ветки: `/cinematic/voxel-factory.html`. Начальная сцена — безжизненная земля и три путника. Пять основных действий — город, лес, вулкан, энергия, идея; река и ход — дополнительные кнопки.

Камера следует за мышью и одним пальцем. Строительство доступно только на видимом участке; размещённые блоки остаются в глобальных координатах. Последствия локального детерминированного preview: вулкан → лава → пар у реки, выгоревший лес, эвакуация жителей. Состояние хранится в `localStorage`, ключ содержит `world_id`, воспроизводится после reload. Река подключается по четырём соседним сторонам.

## Границы текущей реализации

Это браузерный **демосценарий**, а не выпущенная единая серверная симуляция. `tickFactoryWorld` — чистое preview; сервер World Server ещё не вызывает этот контракт, Telegram ещё не синхронизирован и локальное сохранение не равно Supabase. 8 GLB из PR #336 пока не подключены. 30 FPS на реальном iPhone и 60 FPS desktop не подтверждены. Полные независимое ревью, mobile hardware и release gates обязательны до публикации.
