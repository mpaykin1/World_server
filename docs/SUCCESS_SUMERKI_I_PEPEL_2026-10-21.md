## Что сработало (учиться на этом)
1. **Реестры вместо правок движка**: всё через `defineBiome/Enemy/Brain/Body/Event/Weather/NPC/Relic`; движок правится только скрипт-патчем `patch_ash.py` поверх неизменного `base.html`. База (герой, 21 оружие, камера, HUD) не тронута.
2. **Переносить исходный код, не пересоздавать**: `ashenLib` (воксельный движок) и `ash_gpu.js` взяты как есть; расхождения сверялись по коду, а не по скриншотам.
3. **Белая засветка у костра** — причина была в bloom, а не в слоях тумана. Бисект по слоям не помог; исправление `bloom × 0.12` (у ChatGPT ×0.05). Урок: при белом экране сначала проверять силу bloom.
4. **Облакоподобный туман**: полосатые анизотропные слои + маска пятен `uPatch` для пепла/пыли, затухание спрайтов у камеры `smoothstep(2.5,9,d)`.
5. **Лимиты движка**: `MAX_KINDS` 16→24 (и массивы `[24]` в шейдере), `MAX_FOES`=12. `STALK` виден только в паке — передавать параметром.
6. **События**: директор раз в 20 с; для пепельного режима свои `ashChance/ashCool`. Для проверки событий нужен реальный кадровый цикл `G.play`, `sim()` их не запускает.
7. **Конфликт PR**: перед веткой всегда `git checkout main; git fetch; git reset --hard origin/main` (PR #149 закрыт из-за устаревшего main).
8. **Тесты на живом движке** (Playwright + swiftshader, three@0.160 из node_modules): оружие (`attack(true)` + `sim`), Странник, море/события, длинные прогоны.

## Дополнение 2026-10-21: чёрный пепел и низкие рябые облака
Принято владельцем словом «Отлично» (общее одобрение этой доработки, не PASS всей игры). Артефакт v5, meta6 PR #158.
- Чёрный пепел: 900 тёмных непрозрачных хлопьев, обычное смешивание (не additive), крупнее и быстрее серого. Опция `solid` в `makeAmbientPoints`.
- Рябые облака («чешуя» рядами, по скриншоту владельца): 3 плоскости у самой земли, `makeCirrusLayers`; герой проходит сквозь них как сквозь туман.
- Урок: эффект «заметно, а не светится» = непрозрачный тёмный цвет + normal blending + крупнее точка; на тёмной сцене additive/мелкая точка невидимы. Проверять кадром с отключёнными соседними слоями.
