# Chain Reaction: free city infrastructure (first integrated slice)

Implementation: one authoritative, deterministic city-services projection inside the existing shared consequence engine in supabase/functions/_shared/world-consequence-engine.js. Both Node and Supabase Edge use the same JS core. No GPL/AGPL source, paid API, LLM, GPU, new runtime dependency, extra engine, or scheduled task is bundled. Micropolis, LinCity and Citybound are design inspirations only; their source is not copied or linked.

At world creation and every authoritative tick, cityServices constructs a bounded (max 32 validated houses) minimum-spanning graph. It then dispatches finite aggregate power/water to individual apartment floors with rotating priority. A deterministic accident or volcanic/ecological hazard can sever service-specific links. Existing commissioned solar/geothermal/coal/biofuel, desalination/recycling/wells or workshop/market/tourism projects can supply secondary utility/road anchors and repair some hazard damage; no project changes aggregate supply without the existing resource arithmetic. Road-reachable housing bounds the commuter/jobs projection. Saved world.cityServices contains explicit links, per-house availability and aggregate summary. A bounded anonymous city_services_changed causal event with free deterministic Russian text is emitted when service state changes; Genie cards include local, offline explanations.

Limits: this is a household service projection, not a full traffic simulator, editable grid, pathfinding NPC agents or 3D power-line geometry. Connection topology comes from canonical house coordinates; utility anchors are deterministic virtual placements until Graphics supplies authoritative spatial placement. City services do not double-charge scarce resources or silently change existing Genie-category arithmetic. Legacy worlds hydrate on next tick; no migration or API change is needed. Graphics owner of PR #278 can render world.cityServices.houses, world.cityServices.links, and the public timeline events without client-side economic calculations.

Costs: new gameplay and narration need zero external API calls, inference tokens, paid assets and GPU. Production hosting/database may have usage limits and optional features elsewhere in World Server may use paid providers. This patch provides a usable no-key narration option; it does not pretend every independent paid integration has been removed. Optional AI narration PR #291 is outside this non-overlapping scope.

Release criteria: engine/API/Edge regression tests, exact-head cloud CI, genuine two-family independent Fleet PRE, Ocean protected integration/deploy, independently authenticated deployed Fleet POST, real desktop/mobile visible HUD proof, and measured user visibility >85% before providing any playable link.
