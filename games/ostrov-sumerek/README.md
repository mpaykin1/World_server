# Остров сумерек — движок и контент-паки

Воксельная пиксель-арт игра на Three.js (r160) в одном HTML-файле: остров в сумерках, монеты, 22 вида оружия, тени, медузы, Страж маяка — и **система, через которую в игру добавляется всё новое**: враги, оружие, анимации, биомы, персонажи, реликвии, NPC, погода и события, звуки. Движок ничего не знает о контенте: всё, из чего сделан остров, регистрируют паки.

```
engine/      ядро: генератор, рендер, шейдеры, физика, бой, HUD, события — склеивается по порядку имён
packs/       контент: base (исходная игра), frost (Ледяной фьорд), deep (медузы), keeper (Смотритель + бумеранг)
  <pack>/pack.json         id, name, order (порядок загрузки), desc
  <pack>/*.js              define*() — данные и поведение
  <pack>/art/*.py          пиксель-арт кодом: @tile @weapon @projectile @icon @hero @strip_art
art/         общий инструментарий пиксель-арта (палитры, рампы, маски, обводка, персонажи) и сборка атласов
template/    page.html — разметка, CSS, HUD; сюда вставляется собранный модуль
tools/       build · check · bot · duel · shots · new · bundle · run_js
docs/        ENGINE.md (как устроен движок) · CONTENT.md (все типы контента и поля) · STYLE.md (визуальный стиль и движение)
             ERRORS.md (журнал ошибок — читать перед работой) · ROADMAP.md (что может появиться в игре)
dist/        index.html — готовая игра (тело артефакта), test.html — та же игра с <head> для локального запуска
```

## Быстрый старт

```bash
npm i                                   # three@0.160.0 — только для тестового стенда (в игре three грузится с CDN)
pip install numpy pillow playwright     # арт и браузерные проверки (Chromium + SwiftShader, без GPU)
python3 tools/build.py                  # арт → атласы → бандл → dist/index.html, dist/test.html, node --check
python3 tools/check.py                  # реестр без ошибок + прогон каждого биома × героя в живом кадре
```

Открыть игру локально: `dist/test.html` через любой статический сервер (`python3 -m http.server -d dist`).

## Как мы работаем

Владелец не читает код: он играет по ссылке и отвечает «нравится», «не нравится, потому что…» или «откати». Порядок — **AGENTS.md §21** в корне репозитория:
1. одна новая вещь за раз (`docs/ROADMAP.md`);
2. автотесты;
3. взаимное ревью Claude ↔ ChatGPT в PR;
4. журнал ошибок `docs/ERRORS.md`;
5. владельцу — одна ссылка и 2–3 строки.

## Как добавить контент (цикл)

1. **Заготовка** — `python3 tools/new.py KIND ID --pack PACK --name "Имя" --color "#hex"`
   (виды: `pack melee ranged enemy body brain biome block flora character relic npc event weather sound anim fire projectile ricochet`).
   Шаблон сразу собирается и регистрируется, арт-заглушка рисуется в стиле дома.
2. **Поведение и числа** — правим `packs/<pack>/*.js` (поля — в `docs/CONTENT.md`).
3. **Арт** — перерисовываем заглушку в `packs/<pack>/art/*.py` инструментами `art/pixel.py` (`docs/STYLE.md`).
4. **Сборка и проверка** — `python3 tools/build.py && python3 tools/check.py --no-build`.
5. **Посмотреть глазами** — `python3 tools/shots.py OUT weapon:ID | enemy:ID | biome:ID | character:ID | relic:ID | npc:ID | event:ID | title | mobile`.
6. **Проходимость** — `python3 tools/bot.py --biome ID 1337 7` (все монеты, всё оружие и алтари достижимы, страж, победа).
7. **Публикация** — `dist/index.html` → артефакт; `python3 tools/bundle.py pack` → `dist/source.json` (весь исходник одним файлом).

Правила, которые проверяются: идентификаторы `lower_snake_case`; повторное определение — ошибка, замена — только с `override: true`;
ссылки (анимации, снаряды, тела, мозги, арт) проверяются при старте — ошибки видны в `__isle.registry().errors` и в `tools/check.py`.
