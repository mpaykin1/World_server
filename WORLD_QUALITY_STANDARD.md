# WORLD QUALITY STANDARD V9

1. Source PLY/GLB/SPZ bytes are immutable.
2. Near-field geometry, textures and materials stay at 100% source fidelity.
3. Server does not require paid/discrete GPU.
4. Performance improvements prioritize: avoid work → cache → incremental rebuild → spatial reject → distant cadence → client offload. Never reduce near visual fidelity.
5. Every error becomes fingerprint + root cause + prevention rule + mandatory regression/replay + Protection Pack.
6. Every proven success requires evidence + applicability proof + canary + Quality Genome before propagation.
7. Quality Ratchet floors never decrease.
8. Desktop AI continues diagnose/fix/retest until all locally fixable required gates PASS.

## V10 mandatory quality additions

- Huge assets: bounded-memory windowed/mmap processing where supported.
- Threaded import/BVH: deterministic exact parity + exact fallback.
- Semantic PVS: near/unknown fail-visible.
- Incremental GI: reuse only hash-identical cells.
- Cache transport/chunking/delta: exact SHA reconstruction only.
- Offline/shared caches: runtime-version + SHA isolation; no stale cross-version bytes.
- Performance tuning requires CPU causality evidence first.
- Network/physics replay must be deterministic across repeated seed runs.
- Incremental releases require complete code→asset→bake→game dependency impact.
