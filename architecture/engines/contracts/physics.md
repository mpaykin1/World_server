# Контракт physics — G1

## Вход
`RuleSet` с петлёй перемещения, гравитацией мира и правилами столкновений. Параметры — в SI: расстояние в метрах, время в секундах, ускорение в м/с². Физика должна обеспечивать твёрдые стены и ступени, падение при промахе и плавную камеру без телепортации.

```json
{"loop":{"action":"jump","risk":"fall"},"world":{"gravity":9.81,"maxStepMeters":0.35,"solidLayers":["terrain","wall"]}}
```

## Выход
Структурированный JSON, передаваемый следующему движку через существующий интерфейс без мутации входных данных. Пример конкретной формы, не утверждённый канон отдельной игры:

```json
{"gravity":9.81,"step_heights":[0.15,0.35],"collisions":{"solid":true,"layers":["terrain","wall"]},"destruction":null,"units":"SI"}
```

## Проверка
Проверить конечную положительную gravity, неотрицательные step_heights, непроходимость solidLayers, падение без платформы, отсутствие прохождения сквозь стены и согласование с shared/golden-physics.js. Ошибка входа содержит путь к неверному полю; одинаковые входы дают воспроизводимый результат. Контракт G1 сам по себе не подтверждает наличие модуля G2, теста G3 или интеграции G4/G5.

## Границы
Принятые версии игр и эталоны не изменять. Решения о художественном каноне и качестве игры принимает владелец. Для каждой следующей игры параметры выбираются заново с учётом истории и не должны превращаться в универсальный фиксированный шаблон.
