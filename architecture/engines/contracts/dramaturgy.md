# Контракт dramaturgy — G1

## Вход
`GameCard {id, genre, durationMinutes, startingLocation, characters[]}`, `CalcProfile?`, `ownerInterview?`, **`RecentGamesLog` (журнал последних игр)** и **`randomSeed` (зерно случайности)**. Решения Q1–Q12 берутся из `OWNER_DECISIONS.md`. Короткая игра до 15–20 минут: обязательны линии герой–друг, герой–враг, герой–тайна; для длинной — все линии; любовь необязательна, тайна и потеря обязательны. Независимо от длины учитывать четыре уровня конфликта: с собой, с другими, с миром, со временем.

Пример входа:
```json
{"game":{"id":"example-42","genre":"adventure","durationMinutes":18,"startingLocation":"bridge","characters":[{"id":"keeper","motive":"protect_archive"}]},"recentGames":[{"primaryConflict":"self","twistType":"betrayal","endingType":"tragic","finalLocation":"ruins","interferenceSourceType":"friend"}],"randomSeed":42}
```

## Выход
`StoryBible`: `characters[]`, `conflicts{self,others,world,time}`, `primaryConflict` (основной), `secondaryConflict`, `conflictCause`, `twist{type,clues[2..3]}` (один из десяти), `mysteryMechanics[2..3]{type,exposure}`, `interferenceSource{type,id?,motive,suspects[]}`, `choiceTypes[5..7]`, `endings[2..]{type,finalLocation,traceConditions}`, `stagePacing{setup,development,climax,resolution}`, `hurtfulTwistRepair{type,trigger,payoff}`, `world_laws[]`, `lines[]`. Пример структуры, не канон игры:
```json
{"primaryConflict":"society","secondaryConflict":"time","twist":{"type":"false_victory","clues":["seal","timestamp"]},"mysteryMechanics":[{"type":"forged_note","exposure":"paper_date"},{"type":"false_witness","exposure":"contradiction"}],"interferenceSource":{"type":"stranger","id":"keeper","motive":"protect_archive","suspects":["keeper","guide"]},"choiceTypes":["trust","sacrifice","truth","inaction","informed"],"endings":[{"type":"redemption","finalLocation":"cave","traceConditions":{"mercy":2}},{"type":"bittersweet","finalLocation":"island","traceConditions":{"sacrifice":2}}],"stagePacing":{"setup":"bursts","development":"slow","climax":"medium","resolution":"fading"},"hurtfulTwistRepair":{"type":"echo","trigger":"loss","payoff":"world_remembers"}}
```

## Общий протокол вариативности
Вход `RecentGamesLog`: массив завершённых игр в хронологическом порядке, каждая запись содержит `primaryConflict`, `twistType`, `endingType`, `finalLocation`, `interferenceSourceType`, `stagePacing`, `repairType`, `choiceTypes`; `randomSeed` — целое безопасное число для воспроизводимого выбора. История не должна включать текущую игру. Одинаковые seed и журнал дают одинаковый результат. Если доступные варианты исчерпаны, вернуть `NO_VARIANT`, а не нарушить ограничения.

Основной конфликт не совпадает ни с одним из последних трёх. Тип твиста, концовки, место финала, тип источника помех и комбинация четырёх скоростей не совпадают с предыдущей игрой. Тип твиста откладывается на несколько игр; в одной игре один тип не повторяется. Два соседних выбора одного вида запрещены. История обновляется только после завершения игры, атомарно, с выбранной веткой концовки. Применение ограничений — до жребия, а не после.

Типы твиста (ровно 10): ложный след; предательство; разоблачение личности; раскрытие мотива; узнавание; переворот положения; ложная победа; ненадёжный рассказчик; поворот времени или взгляда; переосмысление причин. Перед каждым твистом нужны 2–3 проверяемые ранние подсказки. Виды «починки» обидного поворота: возможность исправить, ответная правда, новая связь, простить или нет, отложенная награда, эхо; тип не повторяется подряд.

Механики тайны (выбрать 2–3 с доказуемым способом разоблачения): слух, искажение при передаче, подделанная записка, ложный свидетель, подброшенная улика, самозванец, двойной агент, шантаж, отвлекающий манёвр, смена лояльности, правда с опозданием, дар с подвохом, ненадёжная память, старая обида, дефицит времени. Источник выбирается по мотиву среди персонажей, цепочки или «никто»; минимум два подозреваемых, один ложный.

Виды выбора (5–7 разных на игру): вслепую, информированный, исход действия, случайная ветвь, вне задуманного, характерообразующий, развилка с мотивацией, атмосферный, доверие, жертва, кого спасти, правда/скрыть, простить/наказать, бездействие, без хорошего выхода, скрытое последствие. Атмосферные выборы — не более трети. Следы поведения: доверие, жертва, правда, милосердие, бездействие. Текст реплик — только в меню ☰, на игровом экране жесты и иконки.

Концовки: счастливая, горько-сладкая, трагическая, искупление, поворот, замкнутый круг, неоднозначная, открытая, обрыв на напряжении, эпилог. Не менее двух доступных концовок с условием на следы игрока и конкретным местом финала; место не равно стартовому (исключение — замкнутый круг). Возможные места зависят от типа: сад/храм, остров/море, руины, пещера, лабиринт, дом/дорога, лес/сон, пустыня/космос, тоннель, изменённое место начала. Четыре независимых темпа `setup`, `development`, `climax`, `resolution`: каждый из slow, medium, fast, bursts, fading; не навязывать одну стандартную кривую.

## Проверка
`test/engines-nonrepeat.test.js`: две последовательные игры различаются по `primaryConflict`, `twistType`, `endingType`, `finalLocation`, `interferenceSourceType`. Проверить 2–3 подсказки, 2–3 механики с разоблачением, мотив источника, два подозреваемых, 5–7 видов выборов, не менее двух концовок с локацией и условием, четыре отдельных темпа, «починку» болезненного поворота. При исчерпании вариантов — ошибка, не повтор.
