# Контракт движка <id> (шаблон; копируй в <id>.md)

Файл `<id>.md` считается контрактом (пункт G1), если в нём есть разделы «Вход», «Выход», «Проверка» и не меньше 500 знаков. Пиши коротко и проверяемо, без общих фраз.

## Вход
Имя формата и поля (тип, обязательно ли). Откуда берётся (какой движок выше по цепочке или карточка игры).

## Выход
Имя формата и поля. Кто потребляет (какой движок ниже по цепочке). Пример на 5–15 строк JSON.

## Проверка
Список проверок «да/нет», которые выполняет код или тест (не «сделать интереснее»). Какой тест их запускает.

## Границы
Что движок НЕ решает (канон игр решает владелец, см. OWNER_DECISIONS.md).
