# Контракт calc — G1

## Вход
Формат: `CharacterSeed`. Цепочка: calc? → dramaturgy. Источник — карточка игры или результат предшествующего движка. Обязательные поля определяются схемой; необязательные данные нельзя заполнять вымышленными значениями. При отсутствии обязательного поля возвращается структурированная ошибка с именем поля. Пример входа:

```json
{"name":"Герой","traits":["осторожность"]}
```

## Выход
Формат: `CalcProfile | null`. Выход передаётся следующему движку без скрытого состояния и без изменения входного объекта. Каждый результат содержит понятные поля, допускает сериализацию JSON и проверку схемой. Пример формы выхода (не утверждение канона игры):

```json
{"source":"fictional","traits":["осторожность"],"timeline":[]}
```

## Проверка
1. Проверить обязательные поля и типы входа; отклонять невалидные структуры с указанием пути.
2. Проверить сериализацию результата, отсутствие мутации входа и повторяемость на одинаковых данных.
3. Проверить интеграцию с соседним движком и отсутствие неразрешённых ссылок.
4. Проверить негативный случай с пустым или повреждённым входом.
5. При реализации G3 добавить автоматическую проверку в `test/engines-calc.test.js`; G1 сам по себе не означает готового модуля, теста или игры.

## Границы
Имя обязательно; birth и traits необязательны. Не рассчитывать судьбу как научный факт; provenance и метод обязательны при ненулевом результате. Отсутствие согласованных данных возвращает null, а не вымышленный прогноз. Авторский канон, судьбы героев, качество игры и художественные решения утверждает владелец; нельзя выдавать схему за готовый сюжет или подтверждённый игровой PASS. Запрещено менять принятые версии и эталонные игровые файлы.
