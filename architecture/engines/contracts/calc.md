# Контракт calc — G1

## Вход
`CharacterSeed {name:string, birth?:string, traits?:string[]}`, `method?: natal|socionics|human_design`, `randomSeed?:integer`. Движок необязателен: без метода возвращает null. Натальная карта PR #534 — пример вымышленного персонажа, не научный факт.

```json
{"name":"Ива","birth":"2001-05-12","traits":["сомневается"],"method":"socionics","randomSeed":17}
```

## Выход
Структурированный JSON, передаваемый следующему движку через существующий интерфейс без мутации входных данных. Пример конкретной формы, не утверждённый канон отдельной игры:

```json
{"source":"socionics","traits":["осторожный_выбор"],"timeline":[],"disclaimer":"fictional_character_design"}
```

## Проверка
Проверить перечисление методов, формат даты и null без метода; не выводить медицинский диагноз, реальную судьбу или психологическую оценку человека. Результат пригоден только как необязательный вход dramaturgy. Ошибка входа содержит путь к неверному полю; одинаковые входы дают воспроизводимый результат. Контракт G1 сам по себе не подтверждает наличие модуля G2, теста G3 или интеграции G4/G5.

## Границы
Принятые версии игр и эталоны не изменять. Решения о художественном каноне и качестве игры принимает владелец. Для каждой следующей игры параметры выбираются заново с учётом истории и не должны превращаться в универсальный фиксированный шаблон.
