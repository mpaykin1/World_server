# Контракт onboarding — G1

## Вход
`RuleSet`, `StyleSheet.ui_icons`, `controls {keyboard,touch}`, `firstRun:boolean`. Первый вход — не текстовая инструкция, а контекстная иконка, анимация и ответ на действие. Skip и replay доступны через ☰.

```json
{"ruleSet":{"loop":{"action":"jump"}},"styleSheet":{"ui_icons":["jump","move"]},"controls":{"keyboard":["Space","WASD"],"touch":["tap","swipe"]},"firstRun":true}
```

## Выход
Структурированный JSON, передаваемый следующему движку через существующий интерфейс без мутации входных данных. Пример конкретной формы, не утверждённый канон отдельной игры:

```json
{"steps":[{"trigger":"first_movement","icon":"move","effect":"pulse","completeOn":"move"},{"trigger":"first_gap","icon":"jump","effect":"arc","completeOn":"jump"}],"skip":true,"replay":true,"textPlacement":"pause_menu_only"}
```

## Проверка
Проверить достижимость каждого trigger, completion без текста, возможность пропустить и повторить, одинаковую игровую логику на клавиатуре и таче; подсказки не блокируют управление и не ломают паузу. Ошибка входа содержит путь к неверному полю; одинаковые входы дают воспроизводимый результат. Контракт G1 сам по себе не подтверждает наличие модуля G2, теста G3 или интеграции G4/G5.

## Границы
Принятые версии игр и эталоны не изменять. Решения о художественном каноне и качестве игры принимает владелец. Для каждой следующей игры параметры выбираются заново с учётом истории и не должны превращаться в универсальный фиксированный шаблон.
