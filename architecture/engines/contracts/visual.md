# Контракт visual — G1

## Вход
`PhysicsConfig`, `StoryBible.world_laws`, `referenceIds[]`, `performanceBudget`. Четыре слоя: дальний фон, средний план, передний план, экран. Стилизация не изменяет физические коллизии; визуальный эталон не заменяется произвольной генерацией.

```json
{"physics":{"gravity":9.81,"collisions":{"solid":true}},"world_laws":["permanent_fog"],"referenceIds":["approved_pixel_01"],"performanceBudget":{"targetFps":30}}
```

## Выход
Структурированный JSON, передаваемый следующему движку через существующий интерфейс без мутации входных данных. Пример конкретной формы, не утверждённый канон отдельной игры:

```json
{"palette":["#080d1a","#d9a85c"],"tiles":["bridge"],"sprites":["hero"],"lighting":{"fog":{"density":0.025},"bloom":true},"ui_icons":["health","pause"],"layers":["far","mid","near","screen"]}
```

## Проверка
Проверить контраст и читаемость персонажа, соответствие approved reference, отсутствие игрового текста вне меню ☰, отсутствие несоответствия физике, прозрачные границы слоёв и измеримый FPS в браузерной проверке. Ошибка входа содержит путь к неверному полю; одинаковые входы дают воспроизводимый результат. Контракт G1 сам по себе не подтверждает наличие модуля G2, теста G3 или интеграции G4/G5.

## Границы
Принятые версии игр и эталоны не изменять. Решения о художественном каноне и качестве игры принимает владелец. Для каждой следующей игры параметры выбираются заново с учётом истории и не должны превращаться в универсальный фиксированный шаблон.
