# Решения владельца Q1–Q12

Источник: предоставленный владельцем в этом разговоре 02.11.2026 документ «Окончательный план: сюжетный движок и решения Q1–Q12» (сообщение с приложением; публичной ссылки на сообщение нет). Документ сам называет эти решения черновиком, но в текущем сообщении владелец прямо поручил записать их и снять блоки Q4, Q6, Q12. Отдельный URL сообщения не выдумывается.

| Вопрос | Решение владельца |
|---|---|
| Q1 | Счастье героя выбирается из 10 вариантов; не повторять в соседних играх. |
| Q2 | Арка выбирается из пяти базовых и пяти дополнительных вариантов; не повторять подряд. |
| Q3 | Предатель, возлюбленный и наставник вариативны; предательство получает механизм «починки», варианты не повторяются подряд. |
| Q4 | Короткая игра до 15–20 минут: герой–друг, герой–враг, герой–тайна. Длинная: все линии. Любовь можно опустить; тайну и потерю — нельзя. |
| Q5 | Родитель, Взрослый, Ребёнок, по два подтипа; шкала «затейник ↔ формальный» — пять ступеней, меняется по сценам; Хитрец и Тихоня необязательны. |
| Q6 | Один режиссёр и трое подчинённых — придумщик, проверяющий, рассказчик; не более трёх исправлений сцены. GPT сверяет роли с реально доступными четырьмя помощниками; их фактический состав пока не подтверждён. |
| Q7 | Общего темпа и жанра нет; завязка, развитие, кульминация и развязка получают независимые скорости. FlyingHero — пример, не универсальный канон. |
| Q8 | Место развязки выбирается по семейству концовки; не совпадает с началом, кроме замкнутого круга; не повторяется подряд. Комикс не задаёт канон. |
| Q9 | Несколько концовок; десять типов, выбор по следам поведения игрока и истории предыдущих игр. |
| Q10 | Основной конфликт и его причина меняются; основной тип не встречается в последних трёх играх. |
| Q11 | Источник помех и механики тайны выбираются жребием среди мотивированных персонажей, цепочки или «никто»; тип источника не повторяется подряд. |
| Q12 | Вымышленная натальная карта PR #534 — пример; необязательный calc может использовать натальную карту, соционику или Human Design как художественный инструмент, не как научно доказанную систему. |

## Границы
FlyingHero и ASQURA — примеры, а не канон других игр. Для Q6 состав реально доступных агентов требует проверки, но выбор структуры и лимита исправлений принят. Правило неповторения, типы твистов, механики тайны, концовки и темпы определены в приложенном плане; G1 не равен реализации G2/G3.
