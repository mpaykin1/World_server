# Очередь решений владельца

Автозадачи не придумывают канон. Если пункту нужен ответ, они берут следующий пункт и ждут здесь. Владельцу задают не больше одного вопроса в сутки, формулировка «да / нет / вариант». Ответ записывает владелец или Claude со ссылкой на сообщение владельца; ответ без ссылки не считается.

Источник вопросов Q1–Q11: раздел 21 `docs/dramaturgy/UNIVERSAL_RULES.md`.

| ID | Вопрос | Что блокирует | Ответ |
|---|---|---|---|
| Q4 | Для каких жанров допустимы исключения из полного набора сюжетных линий? | dramaturgy G3 (тест правил по жанрам) | |
| Q5 | Какие подтипы транзактного анализа и шкалу формальности зафиксировать? | расширение StoryBible | |
| Q6 | Кто главный из четырёх AI-агентов, какие у них функции, каков лимит циклов исправления? | dramaturgy G3 | |
| Q7 | Темп, жанр, способ выбора и форма диалогов FlyingHero? | карточка FlyingHero | |
| Q1–Q3, Q8–Q11 | Канон FlyingHero и ASQURA (счастье, арка, возлюбленный, предатель, причина штурмов и т. д.) | только карточки этих игр, не сами движки | |
| Q12 | Использовать ли публичный архив вымышленной натальной карты (World_server PR #534) как данные движка вычислений? | calc G4, G5 | |

Ответ владельца записывается в столбец «Ответ» с датой. После ответа блок снимается в `engines.json` (`blocked_by_owner`) отдельным PR.
