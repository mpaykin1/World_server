# Одна следующая задача

Реализовать **публичный MCP Streamable HTTP** с настоящими `list_games` и `inspect_game` на основе `ASSET_INDEX.json` (никаких фиктивных функций). Сначала проверить актуальный протокол MCP и наличие существующего MCP-кода в `World_server`; затем интегрировать без дублирования. Проверить JSON-RPC, Origin, ограничения чтения; только после проверки развёртывать бесплатно. Пока разрешённых к распространению ассетов 0, `get_asset` и `get_source` не включать. Не трогать игры и G1–G5 движков.
