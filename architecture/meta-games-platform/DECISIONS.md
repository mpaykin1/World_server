# Технические решения

- Играми и источниками управляют `meta6/SOURCE_INDEX.md`, `meta6/game-source-index.json`; библиотека содержит только проверенное подмножество.
- Отсутствие лицензии на повторное использование означает `unverified` и запрет свободного скачивания/комбинирования; собственные права надо установить отдельно.
- Семь движков используют существующие контракты `architecture/engines`; очередь платформы вторична к срочным ошибкам и движкам.
- MCP единственный: `architecture/meta-games-platform/mcp/worker.mjs`; Netlify подключает **адаптер** без второго набора операций.
- Cloudflare Free заблокировал новые Workers (`10037`, лимит 100); существующие Workers не удалять.
- Vercel Hobby запрещает коммерческое использование, поэтому его не использовать для рекламной платформы.
- Netlify Free допускает коммерческие сайты в рамках лимитов; существующий Netlify-хостинг World_server — кандидат на первый адрес. Счётчик дохода и failover не считать рабочими до реальных проверок.

- Render Free используется только как **подтверждённый HTTPS preview** существующего MCP Worker, без второй реализации протокола. Render прямо не рекомендует Free для production и засыпает после 15 минут без трафика; коммерческую production-платформу не объявлять готовой. GitHub Actions run 41632054496 подтвердил реальный HTTPS.

- Тестовые файлы Netlify должны лежать вне `netlify/functions/`; иначе они могут автоматически обнаруживаться как отдельные функции. Netlify CLI сборка, Deploy Preview и реальные HTTPS-запросы обязательны перед слиянием.
