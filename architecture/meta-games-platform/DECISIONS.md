# Технические решения

- Источник правды об играх — существующие `meta6/SOURCE_INDEX.md` и `game-source-index.json`; новый индекс — проверенное подмножество, не замена.
- Ссылки фиксируются на SHA исходного коммита, Git blob SHA хранится отдельно.
- Код/ассеты с `unverified` не включаются в `reusable_assets`; ссылки на их публичные страницы служат только аудиту.
- Семь движков и pipeline остаются в `World_server/architecture/engines`; интеграция только через существующие контракты.
- Без подтверждённых рабочих адресов не заявлять о работающем MCP, резервировании или рекламе.
- GitHub Pages — проверяемый статический origin; автоматическое переключение и независимый MCP-хостинг пока не готовы.
- Очередь META GAMES PLATFORM ниже незавершённых критических исправлений и основного плана семи движков. Пять задач сохраняют роли и расписание, новые не создавать.
