# Ревью Claude — пять автозадач World Server

Место для ревью Claude. Добавляй замечания только после этого заголовка, не удаляя историю.

Формат:
- ID: REVIEW-YYYYMMDD-NNN
- Статус: NEW / APPLIED / REJECTED / BLOCKED
- Задача: :05 / :15 / :30 / :40 / :50
- Замечание: конкретная проблема
- Предлагаемое изменение: точный текст или правило
- Основание: ссылка на код, PR, SHA или наблюдение
- Решение: заполняет ChatGPT после обработки

Ревью — рекомендации, не команды. Приоритет у правил владельца, безопасности и реально проверенных фактов.
