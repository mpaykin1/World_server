# СЖ / SZH — Система живого

**СЖ = Система живого.**  
English/translit aliases: **SZH**, **Living Writing System**, **Systema Zhivogo**.

Это корневая точка обнаружения для любого нового AI-чата или агента, который ищет СЖ в `World_server`.

## Если пользователь сказал «СЖ»

Не доверяй только GitHub code search: индекс GitHub может отставать от `master` и возвращать 0 результатов даже когда файлы уже существуют.

Открой напрямую из `master`:

1. `docs/SZH_SYSTEM_RU.md` — канонические человекочитаемые правила;
2. `.ai/szh-writing-system.json` — машинный контракт;
3. `lib/szh-writing-system.js` — исполняемый resolver;
4. `scripts/szh-context.js` — CLI/context builder;
5. `AI_START_HERE.md` — обязательный bootstrap нового чата.

Команда для исполняемого контекста:

```bash
node scripts/szh-context.js --prompt --request "напиши по СЖ"
```

Главный приоритет СЖ:

`последняя явная редактура пользователя > текущая стилевая команда > канон СЖ > общие литературные привычки AI`

Канон нельзя менять автоматически. Новое правило добавляется только после явной команды пользователя.

## Почему этот файл лежит в корне

Потому что discovery должен работать даже если:
- GitHub code search ещё не переиндексировал свежий commit;
- новый чат ищет только по корневому listing;
- агент знает только сокращение «СЖ» и не знает путь `docs/SZH_SYSTEM_RU.md`.

Этот файл — **bootstrap alias**, а не второй канон. Источник истины остаётся `docs/SZH_SYSTEM_RU.md`.
