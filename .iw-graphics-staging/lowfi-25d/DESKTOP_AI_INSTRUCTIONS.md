# DESKTOP_AI_INSTRUCTIONS — LOWFI 2.5D SERVER SCENE

Цель: внедрить сцену в `C:\Users\user\Desktop\World_server` без изменения существующих приложений.

## Что уже сделано
- `apps/lowfi-25d/index.html` — клиент с Canvas 160×90, максимально примитивная пиксельная 2.5D-графика.
- `api/lowfi-25d-scene.js` — Vercel/serverless API, который процедурно генерирует:
  - грязь и трещины на стенах;
  - seed сцены;
  - палитру;
  - параметры мерцания лампы;
  - дыхание, руки, голову, моргание;
  - движение тени.
- Клиент сначала использует API сервера.
- Если API недоступен, автоматически включается встроенный fallback и сцена всё равно работает.

## Действия desktop AI
1. Запустить `INSTALL_TO_WORLD_SERVER.bat`.
2. Убедиться, что создана ветка `opencode/lowfi-25d-server-scene`.
3. Не менять и не удалять существующие apps/API.
4. Проверить локально или на Vercel:
   - `/api/lowfi-25d-scene?seed=test` возвращает JSON 200.
   - `/apps/lowfi-25d/` открывает сцену.
   - лампа мерцает;
   - персонаж дышит, моргает и слегка двигает руками/головой;
   - canvas сохраняет намеренно экстремально низкое разрешение;
   - мобильный экран работает;
   - ошибок JS в console нет.
5. Если Vercel Git Integration создаёт preview deployment — вернуть пользователю точную preview-ссылку `/apps/lowfi-25d/`.
6. После успешной проверки НЕ вливать в master автоматически, если это может затронуть production. Сначала оставить рабочий preview.
