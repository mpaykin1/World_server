# Open-source toolchain V2

- Aironzak/instagram — MIT: upstream reference for roomwalk/exploded.
- Pillow — open-source image/APNG/WebP processing.
- NumPy — open-source numerical frame metrics.
- imageio-ffmpeg / FFmpeg — video decode/encode/frame extraction and CPU interpolation. FFmpeg build licensing must be rechecked if build/options change.
- glTF-Transform — MIT: glTF optimization and animation/keyframe compression workflow.
- meshoptimizer — MIT: mesh and animation data compression used with glTF tooling.
- Godot — MIT where Godot projects are present.

Paid services, including Higgsfield, are optional and never required by the core.
